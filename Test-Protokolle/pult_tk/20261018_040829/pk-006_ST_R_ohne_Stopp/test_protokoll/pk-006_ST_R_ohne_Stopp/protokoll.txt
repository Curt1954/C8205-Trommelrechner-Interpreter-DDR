Test pk-006_ST_R_ohne_Stopp

== 1. Ausgangsbedingungen ==
Trommeldatei (uebernommen, Ausschnitt; nicht genannte Zellen = 0):
  0000: 00000005020
  #DOK-0001 ST R ohne vorherigen Stopp: ST ist wirkungslos.
  #TROMMEL=LEER (Trommel vor dem Test geleert: alle 4096 Zellen = 0; danach die Zeilen von Trommeldatei:)
  #PROT STUFE=2
Tastenfolge: ST R
  ST : elektronisch verriegelt, Rechner steht weder im bedingten noch im unbedingten Stopp -> keine Wirkung
  R  : Schalter H-R -> "R", Flag H := 0, US := 0; Interpretation beginnt bei Konnektor B
  Nicht spezifizierte Register (AC, ...) starten mit 0.

== 2. Zustaende des Knotenautomaten ==
  BR=0000 000  (vor Knoten 002)  BZ=0000 AC=00000000000 FÜ=0 V1=0 V2=0 V3=0

== Ende ==
Unbedingter Stop (US:=1)
BZ=0001 AC=00000000000 AR=0005 FE=0 FUE=0 BS=0 US=1 E=0 A=0 V1=0 V2=0

== 3. Ergebnispruefung ==
Ergebnispruefung:
  BZ: soll=0001 ist=0001 OK
  AC: soll=00000000000 ist=00000000000 OK
  AR: soll=0005 ist=0005 OK
  FE: soll=0 ist=0 OK
  FUE: soll=0 ist=0 OK
  BS: soll=0 ist=0 OK
  US: soll=1 ist=1 OK
  E: soll=0 ist=0 OK
  A: soll=0 ist=0 OK
  V1: soll=0 ist=0 OK
  V2: soll=0 ist=0 OK
  0000: soll=00000005020 ist=00000005020 OK
